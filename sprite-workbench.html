How to build a car

Start from a realistic example or choose New car and replace the body with your master. Use Native layer to work on a component at its original resolution. Drag a freehand lasso; Magnetic lasso snaps the outline to nearby color or transparency edges. Color select traces a connected area within the tolerance. Add/subtract selections to refine it, then copy or cut the region into a separate layer.

Use Place hubs to drag cyan centers and radius handles. All anchored wheel, rotor and caliper layers follow that axle. Set pivot marks the hub inside the selected component. The animation preview keeps calipers stationary. Save project retains images, originals, notes and metadata; Export ZIP produces a draft for the skill's full QA and visual review.

For AI rework, write a layer instruction and save the project. Ask Codex to rework that layer using the project; then use Replace layer image to load the result. This local editor provides manual drawing and imports generated images. Image generation runs through Codex.
